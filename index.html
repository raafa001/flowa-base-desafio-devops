Execução guiada

Linha do tempo operável

Tempo total estimado: 32 min

  1. 01 · Pré-requisitos

    Clonar repositórios e configurar secrets

    `git clone git@bitbucket.org:flowa/infra-terraform.git && git clone git@bitbucket.org:flowa/app-dotnet-service.git`

  2. 02 · Infraestrutura

    Provisionar com Terraform

    `terraform init && terraform plan -var-file=envs/prod.tfvars && terraform apply`

  3. 03 · Aplicação

    Build & deploy da API

    `dotnet test && dotnet publish -c Release`; Docker push & sync com Argo Rollouts.

  4. 04 · Verificação

    Smoke tests + Observabilidade

    Executar collections Bruno/Postman, validar métricas no dashboard e confirmar SLOs.

Playbook rápido

  1. Validar alarmes CloudWatch e métricas canary.
  2. Executar `kubectl top pods` / `stern` para logs em tempo real.
  3. Acionar @sre-staff se incidente ultrapassar 15 min.
